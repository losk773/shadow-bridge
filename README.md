# Тень-мост

Прототип мобильной казуальной игры в одном HTML-файле: Canvas 2D, без внешних библиотек.

**Играть:** https://losk773.github.io/shadow-bridge/

## Суть

Человечек сам идёт слева направо. Над уровнем висят предметы, сверху — лампа.
Тени предметов проецируются на землю по формуле центральной проекции:

```
x' = Lx + (x - Lx) * (G - Ly) / (y - Ly)
```

Тень над провалом — твёрдый мост. Чем ближе лампа к предмету, тем длиннее тень.

## Управление

- Палец/мышь в любой точке экрана двигает лампу **относительно** смещения пальца.
- Уровень 8: тап по иконке переключает активную лампу.
- Отладочные ссылки: `#play=5` — сразу уровень 5, `&t=3` — промотать 3 секунды,
  `&lamp=420,240` — поставить лампу в точку.

## Уровни

Данные уровней — обычный JS-массив `LEVELS` в начале файла: `gaps`, `objects`
(`box` и `pendulum`), `gates`, `coins`, `lamps`. Новый уровень = новый объект в массиве.

## Как это проверялось

Логика игры вынесена в отдельный `<script>` между маркерами `<!--CORE-START-->` и
`<!--CORE-END-->` и не трогает DOM — её можно выполнить в node. Тесты в `tests/`:
юнит-тесты геометрии и автопилот-планировщик, который проходит каждый уровень
человекоподобным управлением (лампа движется с ограниченной скоростью).

```
node tests/play.mjs        # все уровни
node tests/play.mjs 1,2,3  # выборочно
```
